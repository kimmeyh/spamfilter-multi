# Release notes -- 0.18.0 -- Microsoft Store

**PROVISIONAL** -- written at Sprint 77 plan approval (2026-10-06, Phase 3.7.0b) from the approved scope; re-derive from
the finished CHANGELOG at Phase 7.7 (STORE_RELEASE_PROCESS.md Step 1b).

**Range**: everything after 0.17.6 (Submission 31).

---

You can now choose how often each account is scanned in the background, from every 5 minutes to every 99 hours.

You can now add an email account from any provider that supports IMAP, with a server address, port and encryption you enter yourself.

Fixes: moving Gmail mail to a label you created, and the same "No rule" email no longer appearing many times.
