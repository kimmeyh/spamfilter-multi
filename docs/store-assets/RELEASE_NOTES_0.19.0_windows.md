---

Every file the app saves for you now goes to one folder: MyEmailSpamFilter in your Documents folder. That includes scan exports and the diagnostic log. If you chose a folder in Settings, the app keeps using it, and files already saved are not moved.

Review No Rule Items now looks and works like the Results screen: search, account, folder and sort choices, and the same email detail view when you select an email.

The "Scan every" setting now ranges from 5 minutes to 24 hours, and it appears only when background scanning is on.
