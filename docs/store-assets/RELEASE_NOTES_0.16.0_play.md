<en-US>
Background scans now run while your phone is idle or the screen is off. Before, they often only
ran while the app was open.

You can cancel a scan that is taking too long, from the screen you are already on.

When an account is set to read-only, the app now shows what it would have filed, so you can check
a new rule before letting it act.

The app version is visible on every screen.
