Back up or share rule sets via YAML files. Export saves rules.yaml and rules_safe_senders.yaml where you choose; the save dialog opens in the export folder (MyEmailSpamFilter in Documents unless you chose another). When you import a file, you choose how it is applied. Merge (the default) adds only the rules or safe senders you do not already have; duplicates and invalid patterns are skipped, and the result tells you how many were added and how many were skipped. Nothing you already have is changed or removed. A rule with the same name as one you have is treated as a duplicate and is never overwritten. Replace deletes all existing rules (or safe senders) of that type and loads the file's set instead. Import files are capped at 10 MB and parsed with ReDoS detection -- dangerous patterns are rejected at parse time.
